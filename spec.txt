# ARTTENT Landing Page Specification

## 1. Overview
A single-page, mobile-first landing website for **ARTTENT – Art Business Management Company**. The page positions ARTTENT primarily for **collectors and buyers**, with a strong secondary message for **artists**, highlighting ARTTENT as an innovative pop-up gallery and full-service art management company.

The page includes sections: Navigation bar, Hero, Benefits, How It Works, Testimonials, Pricing, FAQs, and Footer, plus a reusable contact/modal form.

## 2. Brand & Design System

### 2.1 Brand Personality
- Clean, minimal, contemporary
- Accessible and welcoming, not intimidating
- Confident, cultured, and international

### 2.2 Colors
- **Primary Background**: Soft off‑white `#F9FAFB`
- **Main Text**: Charcoal `#1F2933`
- **Secondary Text**: Muted gray `#6B7280`
- **Accent (Yellow/Orange)**: Warm amber `rgb(234, 165, 6)`
- **Dark Accent**: Deep charcoal `#111827`
- **Light Accent Backgrounds / Cards**: Very light gray `#F3F4F6`
- **Borders / Lines**: Light gray `#E5E7EB`
- **Success / Confirmation**: Emerald `#10B981`
- **Error / Alert**: Red `#EF4444`

Usage:
- Page background: `#F9FAFB`
- Hero highlight elements and buttons: `rgb(234, 165, 6)` with white text
- Secondary buttons / outlines: `#111827` text and border on white background
- Sections alternate between white and very light gray for clear separation

### 2.3 Typography
(Use Google Fonts; names are provided for designers, not for users.)
- **Headings (H1–H3)**: "Bebas Neue", a condensed, modern sans-serif loaded from Google Fonts
- **Body Text**: Simple sans-serif (e.g., system UI stack or a Google Font like "Inter")
- **Style**:
  - Headings: Bold, clear, with generous spacing and strong hierarchy
  - Body: Regular weight, high readability
  - All text left-aligned except for hero and section titles that can be centered on mobile

### 2.4 Spacing & Layout
- **Max content width**: About 1100–1200px, centered
- **Horizontal padding**:
  - Mobile: ~16–20px
  - Desktop: ~40–60px
- **Vertical spacing**:
  - Major sections: ~80–100px top and bottom on desktop, ~56–72px on mobile
  - Space between blocks (e.g., headings and text): ~16–24px

### 2.5 Buttons & Interactions
- **Primary button** (used for main actions like “Book a Consultation” or “Submit”):
  - Background: `rgb(234, 165, 6)`
  - Text: White
  - Shape: Slightly rounded corners
  - Hover: Slightly darker accent (e.g., `rgb(214, 145, 0)`) with subtle shadow
- **Secondary button**:
  - Border: `#111827`
  - Text: `#111827`
  - Background: transparent or white
  - Hover: Light gray background `#F3F4F6`

- **Links**:
  - Text color: `#111827`
  - Hover: Underline and slight color shift toward `rgb(234, 165, 6)`

### 2.6 Imagery & Icons
- **Logo / Wordmark**: Text-only logo using the brand name
  - Wordmark text: `ARTTENT`
  - Styling: "ART" in light color suitable over the hero image (e.g., `#F3F4F6`), "TENT" in accent color `rgb(234, 165, 6)`
- **Hero Image**: Full-width image in hero section
  - `https://cdn.breba.app/maya/acffaf48e69b4ed78bac97ce8f9421f8/assets/art_tent_hero_1920x768.jpg`

  - Use Google icons or other free icon sets via CDN (for benefits, steps, social icons, etc.)

### 2.7 General Style
- Clean, lots of white space
- Clear section separation using background color changes and subtle dividers
- Minimal animations (soft fades or slides) if desired, but not required

## 3. Technical & Global Requirements

- Single `index.html` file
- Use **Bootstrap 5.3.8** via CDN for layout and basic styling (no integrity check):
  ```html
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
  ```
- No inline styles; use `<style>` block in the `<head>` for custom CSS
- Responsive and mobile-first
- Accessible:
  - Proper heading order (H1 then H2, etc.)
  - Alt text on all images
  - Sufficient color contrast
  - ARIA attributes for modal and navigation where helpful
  - Keyboard-focusable links and buttons
- Performance and security:
  - Use compressed external assets only by URL (no unnecessary scripts)
  - Avoid heavy external libraries besides Bootstrap and icons
- SEO optimized (filled meta tags, headings, structured content)
- Support for Google Analytics (placeholder script ID in the spec)
- Use **staticforms.xyz** with AJAX for the contact/modal form
- All navigation links scroll smoothly to sections on the same page

## 5. Navigation Bar

### 5.1 Layout & Content
- Fixed or sticky at the top when scrolling
- Initial background: transparent so the hero image shows behind the navbar on page load
- On scroll (after the user starts scrolling down): navbar background changes to solid `#F9FAFB` with subtle bottom border (`#E5E7EB`) and a light shadow for separation
- Navbar text color behavior:
  - On transparent/dark hero background: wordmark “ART” and all nav links use a light text color (`#F3F4F6`) for contrast, while “TENT” stays in the accent color
  - When the navbar switches to the light background: wordmark “ART” and all nav links switch to dark text color (`#1F2933` with high priority in CSS if needed), while “TENT` remains in the accent color `rgb(234, 165, 6)`
- Left side: **Logo / wordmark** text
  - Wordmark text: `ARTTENT`
  - Clicking logo scrolls to top (Hero section)
- Centered navigation links between logo and any right-side content

### 5.2 Navigation Links
Use smooth scrolling to each section:
- **Benefits** – `#benefits`
- **How It Works** – `#how-it-works`
- **Testimonials** – `#testimonials`
- **FAQs** – `#faqs`

### 5.3 Call-to-Action Button in Navbar
- No separate CTA button in the navbar; primary calls to action are placed in the Hero and other sections.

### 5.4 Mobile Navigation
- Collapsible hamburger menu (Bootstrap navbar toggler)
- Menu items stacked vertically on mobile, including CTA button at bottom of menu

## 13. Modal Contact Form

### 13.1 General
- Single reusable modal used for all CTAs (`Book a Consultation`, `Start Your Collection`, `Request Proposal`, `Discuss a Project`, `Contact Us`)
- Accessible modal using Bootstrap’s modal component
- `aria-labelledby` and `aria-describedby` attributes

### 13.2 Modal Content
- Title: `Let’s Talk About Art`
- Short description under title:
  - `Share a few details about your needs and we will get back to you with curated options from the Georgian art scene.`

### 13.3 Form Fields
Use a standard HTML `<form>` inside modal body.

Visible fields (all with labels and placeholders):
1. **Name** (required)
   - Label: `Name`
   - Placeholder: `Your full name`

2. **Email** (required)
   - Label: `Email`
   - Placeholder: `you@example.com`
   - Input type: `email`

3. **Company** (optional)
   - Label: `Company / Organization`
   - Placeholder: `Your company or institution (optional)`

4. **Message** (required, textarea)
   - Label: `How can we help?`
   - Placeholder: `Tell us if you are a collector, institution or artist, and what you are looking for.`

Hidden fields for StaticForms:
- `subject` – value: `New inquiry from ARTTENT landing page`
- `replyTo` – value: `@`
- `apiKey` – example placeholder: `your-staticforms-api-key` (clearly marked as to be replaced)

### 13.4 Form Integration (staticforms.xyz with AJAX)

Form attributes:
- `method="POST"`
- `action="https://api.staticforms.xyz/submit"`

AJAX behavior (implemented via JavaScript in `<script>` at end of body):
- On submit:
  - Prevent default page reload
  - Send form data using `fetch` or `XMLHttpRequest` to StaticForms API
  - On success:
    - Show a success alert or message inside modal: `Thank you. We will contact you shortly.`
    - Optionally clear fields
  - On error:
    - Show an error message: `Something went wrong. Please try again or email us at art@arttent.ge.`

Buttons in modal:
- Primary submit button:
  - Label: `Send Message`
  - Style: primary accent button
- Secondary close button (in footer or header):
  - Label: `Close`
  - Closes modal without submitting

## 15. Accessibility & SEO Notes

- Use semantic HTML tags for each section (`<header>`, `<main>`, `<section>`, `<footer>`)
- Single H1 in hero section; H2 for each main section; H3/H4 for nested headings
- Descriptive link and button texts (no generic “Click here”)
- `alt` text for all images, especially logo and hero
- ARIA labels for:
  - Navigation (`aria-label="Main navigation"`)
  - Social media icons (`aria-label="ARTTENT on Instagram"`, etc.)
  - Modal (`role="dialog"` with proper `aria-modal="true"`)
- Ensure color contrast meets accessibility guidelines (dark text on light backgrounds; white text on accent buttons)
